# Seguridad / Security

## Español

Si encuentras un problema de seguridad en RoZze, ponte en contacto a través de https://www.orbexs.co.
Por favor, **no abras issues públicos** con detalles explotables: describe el problema en privado y
te responderemos por ese canal. Indica la versión de RoZze y los pasos para reproducirlo.

## English

If you find a security issue in RoZze, please get in touch through https://www.orbexs.co.
Please **do not open public issues** with exploitable details: describe the problem privately and
we will reply through that channel. Include the RoZze version and steps to reproduce.
