# RoZze para Windows — versiones publicadas

**RoZze** es un companion de escritorio para directos de TikTok LIVE: eventos en tiempo real, overlays para tu
emisión y voz local, todo en tu propio ordenador.

## Qué hay aquí

Este repositorio **solo contiene versiones publicadas**:

- el instalador de Windows (`RoZze-Setup-x.y.z.exe`),
- el manifiesto de actualización **firmado** (`rozze-update.json`),
- las sumas de verificación (`SHA512SUMS`).

**No hay código fuente.** RoZze comprueba la firma de cada manifiesto antes de ofrecer una actualización.

## Cómo descargar

- **Desde la propia app:** RoZze te avisa cuando hay una versión nueva y la instala por ti.
- **A mano:** en la sección [Releases](https://github.com/Rocuts/rozze-releases/releases) de este repositorio.
